## استخدام صفحة الفحص

بعد دمج هذا التغيير ونجاح نشر Cloudflare Pages، افتح:

`https://utivaro.com/diagnostics/consent?fc=alwaysshow&fctype=gdpr`

اضغط **ابدأ الفحص** مرة، وانتظر 30 ثانية. إذا ظهرت رسالة Google، يمكن اختيار تفضيلاتك ثم نسخ التقرير. اختيار الموافقة أو رفضها في هذه الصفحة يمكن أن يُحفظ في CMP ويؤثر في الزيارات اللاحقة. أرسل التقرير المنسوخ في المحادثة. إن تعذر النسخ، انسخ النص يدويًا أو أرسل صورة النتائج.

هذه صفحة مستقلة تطلب استجابتين من نفس الموقع: الصفحة الرئيسية وصفحة الفحص. تقبل ترويسات HTTP 200 HTML المطابقة لبنية الصفحة فقط. بعدها تضبط افتراضات الموافقة الأربعة على denied وتسجل callbacks الرسمية وتحمل وسم AdSense نفسه، دون استيراد جسر Utivaro أو محمّل GA4. بذلك يمكن مقارنة وصول Google في صفحة بسيطة مع وصولها في الصفحة الرئيسية.

لا تقرأ الأداة الكوكيز أو التخزين أو سلسلة TCF أو بيانات الأدوات، ولا ترسل تقريرًا إلى خادم أو إلى GA4. تعرض أسماء حالات الموافقة الأربعة فقط، وترويسات السياسة العامة. سجل حظر CSP يقتصر على فئة المورد والتوجيه، لا الروابط الكاملة. قد يضيف المضيف Cloudflare Analytics بصورة مستقلة؛ تحميل وسم AdSense يتصل بـGoogle وقد يعرض رسائل أو إعلانات وفق إعدادات الحساب.

## تفسير النتائج

| النتيجة | ما تثبته والخطوة التالية |
|---|---|
| `page-fetch-failed` | فشل أو اختلاف استجابة الفحص؛ لا نستخدم ترويساتها كدليل على سياسة الصفحة |
| `publisher-mismatch` | لم نجد وسمًا واحدًا بالمعرّف المطلوب في الصفحة الرئيسية المستلمة |
| `restrictive-referrer-policy` | رُصدت سياسة صريحة تمنع معلومات المصدر بين النطاقات؛ افحص مصدرها قبل تعديلها |
| `resource-blocked-by-csp` | المتصفح رصد حظر مورد Google؛ افحص CSP المحددة |
| `adsense-tag-load-error` | فشل تحميل وسم Google؛ لا يثبت وحده مانع إعلانات أو إعدادًا بعينه |
| `tag-loaded-cmp-not-ready` | وصل وسم AdSense، لكن لم تصل جاهزية CMP ضمن نافذة الاختبار؛ السبب ما زال مفتوحًا |
| `cmp-api-ready` | واجهة CMP جاهزة؛ بيانات Consent mode لم تصل بعد، وقد تنتظر اختيار المستخدم |
| `consent-data-received` | وصلت بيانات وضع الموافقة إلى صفحة الفحص؛ راجع القيم، ثم اختبر جسر الموقع وGA4 بصورة منفصلة |

الصفحة غير مضافة لخريطة الموقع أو التنقل وتحمل noindex. نجاحها ليس إثباتًا لقبول AdSense، أو نجاح التحليلات، أو سلامة التوجيه الجغرافي. فحص الظهور الإجباري لا يغني عن زيارة جديدة عادية من المنطقة المستهدفة. يمكن حذف مجلد diagnostics واختباره وتوثيقه بعد إغلاق التشخيص.

مصادر: [Google CMP API واختبار الرسائل](https://developers.google.com/funding-choices/fc-api-docs)، [استكشاف أعطال الرسالة](https://support.google.com/adsense/answer/14660912?hl=en).
