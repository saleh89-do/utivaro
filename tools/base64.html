What Is Base64?

Base64 is a method of representing data using a limited set of text characters. It is commonly used when data needs to be transported or stored in text-based formats.

Developers may encounter Base64 in APIs, data URLs, email systems, configuration files and other software applications.

Base64 Encoding Example

For example, the text Hello becomes:

SGVsbG8=

Decoding SGVsbG8= returns the original text: Hello.

Is Base64 Encryption?

No. Base64 is encoding, not encryption.

Base64 data can normally be decoded easily, so it should not be used to protect passwords, confidential information or other sensitive data.

Does It Support Unicode Text?

Yes. This tool uses UTF-8 conversion so it can encode and decode Unicode text, including many non-English characters.
