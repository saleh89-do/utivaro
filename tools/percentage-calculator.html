How to Calculate a Percentage of a Number

To find a percentage of a number, multiply the number by the percentage and divide the result by 100.

The formula is:

Percentage value = Number × Percentage ÷ 100

For example, to find 25% of 200:

200 × 25 ÷ 100 = 50

Therefore, 25% of 200 is 50.

How to Find What Percentage One Number Is of Another

To calculate what percentage X is of Y, divide X by Y and multiply the result by 100.

The formula is:

Percentage = X ÷ Y × 100

For example, 50 is what percentage of 200?

50 ÷ 200 × 100 = 25%

How to Calculate Percentage Increase

Percentage increase measures how much a value has grown compared with its original value.

The formula is:

Percentage increase = (New value − Original value) ÷ Original value × 100

For example, if a price changes from 100 to 125, the increase is 25%.

How to Calculate Percentage Decrease

The same percentage-change formula can be used when the new value is lower than the original value.

For example, if a value decreases from 200 to 150, the decrease is 25%.

Common Uses for Percentage Calculations

Percentage calculations are useful for discounts, price changes, sales, grades, statistics, business reports, taxes, budgeting and everyday comparisons.

Frequently Asked Questions

How do you calculate 20% of a number?

Multiply the number by 20 and divide by 100. For example, 20% of 150 is 30.

What percentage is 50 out of 200?

Divide 50 by 200 and multiply by 100. The result is 25%.

How do you calculate a percentage increase?

Subtract the original value from the new value, divide the difference by the original value, and multiply by 100.

Can percentages be greater than 100%?

Yes. A percentage can be greater than 100% when a value is larger than the reference value. For example, 300 is 150% of 200.
