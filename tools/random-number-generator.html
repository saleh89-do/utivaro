Random Number Generator

Generate one or many random numbers within a range, with optional decimals and no-duplicate results.

🎲 Random values are generated locally in your browser using cryptographic randomness when available.

Generate random numbers online

Set a minimum and maximum value, choose how many numbers you need and optionally add decimal places or require unique results.

How to use the random number generator

  1. Enter the minimum and maximum values.
  2. Choose the quantity and decimal places.
  3. Optionally enable unique results.
  4. Select Generate Numbers.

Common uses

Random numbers are useful for games, classroom activities, testing, sampling, simulations and any task that needs an unpredictable value within a range.

Frequently Asked Questions

Can I generate more than one random number?

Yes. You can generate up to 100 values at a time.

Can I generate decimal numbers?

Yes. Choose between 0 and 8 decimal places.

Can I avoid duplicate numbers?

Yes. Enable the no-duplicates option. For integers, the requested quantity must fit inside the selected range.

Are the numbers generated on my device?

Yes. The tool runs in your browser and uses browser cryptographic randomness when it is available.
