Count characters instantly

Paste or type text to see live counts for characters, characters without spaces, words, lines and UTF-8 bytes. You can also set an optional character limit.

Character count with a limit

When you enter a limit, the Remaining counter shows how many characters are left. A negative result means the text is over the selected limit.

Characters versus bytes

Character count measures visible text units, while UTF-8 byte count measures the encoded data size. Some characters and emoji use more than one byte.

Frequently Asked Questions

Does the character counter include spaces?

The main Characters count includes spaces. A separate counter shows characters without whitespace.

Can I set a character limit?

Yes. Enter any positive limit and the tool will show the number of characters remaining.

Does it count emoji?

The tool uses browser text segmentation when available so emoji and combined characters are counted more naturally.

Is my text uploaded?

No. The counting happens locally in your browser.
