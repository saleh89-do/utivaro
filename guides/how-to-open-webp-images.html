Why You Can't Open a WebP Image (and How to Convert It)

By Utivaro Team · Last updated September 30, 2026

Websites deliver images as WebP to load faster, so images you save often end up as .webp files. Any current browser can open them. If a form or program won't accept one, convert it with the WebP to JPG converter; renaming the file won't work.

Why you keep getting WebP files

Websites use WebP because it makes pages load faster: a WebP photo is typically a quarter to half smaller than the same photo as JPG. When you right-click an image and choose "Save image as", the browser saves the file exactly as the site delivered it, so you end up with a .webp file even though the picture looked like any other photo on the page.

Browsers display WebP without trouble. Problems start when the file leaves the browser.

Support has improved a lot: current versions of Windows, macOS, Android, iOS and major editors open WebP. Most failures today come from upload forms with a fixed list of formats and from software that hasn't been updated for a few years.

How to open a WebP file right now

  • Any computer or phone: drag the file into a browser window, or open it with Chrome, Edge, Firefox or Safari. Every current browser displays WebP.
  • Windows: the Photos app opens WebP on current Windows versions. If it doesn't, install the free WebP Image Extensions from the Microsoft Store, or open the file in a browser.
  • Mac: Preview opens WebP on recent macOS versions.

How to convert WebP to JPG

  1. Open the WebP to JPG converter and choose the .webp file.
  2. Keep JPG Quality at 92% unless you need a smaller file.
  3. Select Convert to JPG. The tool shows the original size, the JPG size and the dimensions, which stay the same as the WebP.
  4. Select Download JPG.

The conversion runs in your browser; the image is not uploaded.

Why the JPG may be bigger

Don't be surprised if the JPG is larger than the WebP. WebP simply compresses better. In our format comparison, the same indoor photo was 37 KB as WebP and 79 KB as JPG. If the converted JPG is too big for a form, lower the quality slightly or resize it with the Image Resizer.

Transparent WebP images

Logos and cut-out product photos often have a transparent background. JPG can't store transparency, so transparent areas are filled with a solid color when you convert. If you need to keep transparency, convert to PNG instead: the Image Resizer can export PNG at the original width and height.

Avoid these shortcuts

  • Renaming the file from .webp to .jpg changes only the name. The data is still WebP, and a strict form or program will still reject it.
  • Taking a screenshot of the image works, but captures it at your screen's size and may include parts of the page. Converting keeps the full resolution.
  • Browser extensions that "save as JPG" are convenient, but check what permissions they ask for before installing.

Should you convert WebP images on your own website?

No. If you run a site, WebP is the format you want to serve: smaller files mean faster pages. Convert only the copies you need for forms, print or older software. To go the other way and make your site's photos smaller, use JPG to WebP.

Frequently asked questions

Is WebP a safe file format?

Yes. WebP is an ordinary image format, like JPG or PNG. It isn't more likely to contain anything harmful.

Does converting WebP to JPG reduce quality?

Slightly, because JPG is lossy. At quality 90 or above the difference is very hard to see.

Can I stop my browser from saving WebP?

Not reliably. The format is chosen by the website, and the browser saves what it received. Converting afterwards is the dependable route.

Why does the file say .webp but the website showed a JPG?

Many sites and image services automatically serve WebP to browsers that support it, even when the original upload was a JPG.
