فحص تحميل رسالة الموافقة

صفحة مساعدة لصاحب الموقع. لا يغيّر الفحص إعدادات Cloudflare أو AdSense، ولا يحمل Google Analytics.

عند بدء الفحص، نجلب الصفحة الرئيسية ونقرأ ترويساتها، ثم نحمل وسم AdSense المعتاد لاختبار رسالة Google. هذا الجزء يتصل بـGoogle وقد يعرض الرسالة أو إعلانات وفق إعدادات حسابك.

التقرير لا يتضمن ملفات تعريف الارتباط أو معرّفات الزوار أو سلسلة الموافقة. لا يُرسل التقرير تلقائيًا. قد يضيف المضيف تحليلات Cloudflare بشكل منفصل.

جاهز. اضغط «ابدأ الفحص» وانتظر النتيجة.
